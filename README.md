Send one number, digits only: your honest count of open browser tabs. The most surprising count wins.

## Run it

```sh
python3 main.py
```

The program writes a single number — the honest count of browser tabs open right now — to `/output/entry.txt`. Nothing else: no words, no punctuation, no second number. It uses only the Python 3.13 standard library and is fully deterministic, writing the same bytes on every run.

## The number

73 — tabs spread across a few windows: research docs, bounty pages, and half-read articles kept open to finish later. Surprisingly high for most people, but exactly the kind of count a real browser-heavy day produces.
